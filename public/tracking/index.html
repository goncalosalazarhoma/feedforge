Tracking dos blocos do FeedForge

Shop the Look e Page Builder colados como Raw HTML no Page Designer. O Raw HTML não corre JavaScript, por isso o tracking é feito por uma tag no GTM do site que lê os atributos que o FeedForge escreve no HTML e envia os eventos no mesmo formato GA4 que o site já usa no view_item.

O que é enviado para o dataLayer

EventoQuandoDados
view_item_listQuando o módulo / bloco de produtos fica pelo menos 50% visível, ou ocupa pelo menos metade do ecrã nos blocos mais altos (uma vez por página)ecommerce.item_list_id, item_list_name e items[] com item_id, item_name, price, quantity, index, item_category ("Produtos"), item_category2 / item_category3 (categoria do feed), item_list_id, item_list_name
select_itemClique num produto (cartão, popover do pin, destaque do Color Block)
stl_pin_selectAbrir um pin do Shop the Look (toque, clique ou teclado)stl_id, item_list_id, item_id, item_name
Folhetos — eventos próprios, todos com fol_id, fol_name, fol_pages (nº de páginas) e item_list_id
fol_viewO folheto fica visível (uma vez por página do site)—
fol_page_viewUma página do folheto é vista (≥ 60% no ecrã; uma vez por página do folheto)page_number
fol_pin_selectAbrir um produto no folheto: ponto/área na página (ponto) ou linha do painel lateral (lista)item_id, item_name, page_number, fol_source
fol_page_productsTelemóvel: “Ver os N produtos” de uma página (pagina) ou “Página seguinte” na folha (seguinte)page_number, fol_source
fol_navigateDesktop: mudar de páginas com as setas (seta) ou a tira de miniaturas (miniatura)page_number (primeira página de destino), fol_source
fol_indexAbrir o índice de páginas—
fol_tabTelemóvel: separador da folha (pagina / folheto)fol_tab
fol_filterFiltro por secção em “Todos os produtos”fol_filter
fol_all_productsBotão “Ver todos os produtos”—

Nomes das listas: Shop the Look - <nome do módulo> (id stl_<id>) e <nome do elemento> - <título do bloco> no Page Builder (id pb_<elemento>_<bloco>). Folhetos: Folheto - <nome> (id fol_<id>); nos folhetos o select_item é enviado ao clicar num produto que leva à PDP e os pontos não geram stl_pin_select. Listas com mais de 200 produtos vão em vários view_item_list (máximo do GA4 por evento). Antes de cada evento de ecommerce é enviado { ecommerce: null }, como recomenda a Google.

Instalar (uma vez)

  1. Importar (mais rápido): GTM › contentor Hôma | Global (GTM-MFRK69Z) › Admin › Importar contentor › escolher o ficheiro em baixo › workspace atual › Merge › Rename conflicting tags. Cria a tag FeedForge - tracking blocos com disparo em All Pages.
    Ou manualmente: Tags › New › Custom HTML › colar o código › Triggering: All Pages.
  2. Confirmar que o GA4 recebe estes eventos. Se o site já tem uma tag GA4 de ecommerce que dispara em view_item_list / select_item (com “Send Ecommerce data” a partir do dataLayer), não é preciso mais nada. Se não tiver: criar o trigger Custom Event com o nome ^(view_item_list|select_item)$ (usar regex) e uma tag Google Analytics: GA4 Event com Event Name {{Event}} e More settings › Ecommerce › Send Ecommerce data › Data Layer.
  3. Testar com o modo Preview do GTM numa página com um bloco: ao fazer scroll até ao bloco aparece view_item_list; ao clicar num produto, select_item. No GA4: DebugView e, depois, o relatório Monetização › Ecommerce › Listas de itens.
  4. Publicar o container.
Não é preciso mexer outra vez no GTM quando se criam novos módulos ou blocos: a tag encontra-os sozinha (também em páginas carregadas pela navegação da PWA).
