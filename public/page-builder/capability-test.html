Teste de capacidades do Page Designer

Antes de usar o HTML do Page Builder no site, confirma o que o componente Raw HTML do PWA Kit deixa passar. Até lá o Page Builder gera HTML sem JavaScript.

1. Copia este código

2. Cola-o no sandbox de desenvolvimento

  1. Abre o Business Manager do development.homastores.com → Page Designer, numa página de teste.
  2. Adiciona um componente Raw HTML, cola o código e publica/pré-visualiza.
  3. Abre a página no desktop e no telemóvel (ou no modo responsive do browser, < 768px).

3. Vê o resultado

  1. Texto verde em Gilroy → o <style> funciona.
  2. Texto vermelho → style="" inline funciona.
  3. Grelha de 2 colunas que passa a 1 no mobile → media queries funcionam.
  4. Fila bege com scroll horizontal → overflow-x + scroll-snap funcionam.
  5. “JavaScript correu.” → os <script> correm (provavelmente não, se o componente usar innerHTML).
  6. O link relativo abre /pt/pt/produtos.
  7. A imagem da almofada aparece.

Depois, com o botão direito → Inspecionar, procura hpb-test: o id="hpb-test", o data-hpb-test e o data-item-id continuam no DOM, ou foram removidos?

4. Regista o resultado

No FeedForge → Page Builder → “Registar resultado”. Se o JavaScript correr e os data-* se mantiverem, os carrosséis passam a ter setas.
